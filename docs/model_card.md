# Model Card — KGFuse

Author: 晨星 (CJX0712) · Version 0.1.0

## Model details

- **System**: KGForge, knowledge-graph embedding & link prediction
- **Flagship**: `KGFuse` — Reciprocal Rank Fusion over four base embedding models
- **Base models**: TransE, DistMult, ComplEx, RotatE (published algorithms, NumPy implementations)
- **Fusion**: `score(e) = Σ_m 1/(60 + rank_m(e))`
- **Runtime**: pure NumPy, CPU-only, offline, no weight download

## Intended use

- Link prediction / knowledge-graph completion research and benchmarking
- A reproducible reference for comparing embedding models and rank-fusion strategies
- **Not** intended for production knowledge bases or safety-critical decisions

## Training data

Synthetic knowledge graphs generated by `kgforge.data.synthetic.generate_synthetic_kg`:
300 entities, 8 relations (4 semantic types), 1000 train / 200 valid / 200 test triples
(`medium` difficulty = 20% random distractors in train). Fully reproducible from
`(config, seed)`; no personal or licensed data involved.

## Evaluation protocol

Filtered link prediction (Bordes et al. 2013). Metrics: MRR, Hits@1/3/10.
Averaged over head-prediction and tail-prediction queries. 3 seeds: 7, 42, 123.

## Quantitative results

| Method | MRR (mean ± std) |
|---|---|
| TransE | 0.0468 ± 0.0103 |
| DistMult | 0.1717 ± 0.0094 |
| ComplEx | 0.1524 ± 0.0236 |
| RotatE | 0.0828 ± 0.0120 |
| **KGFuse** | **0.2018 ± 0.0277** |

Relative gain over the strongest single model: **+17.56%** (gate ≥ 5% → PASS).
Significance: |Δ| = 0.0301 > ½(σ₁+σ₂) = 0.0186 → SIGNIFICANT.
Random-ranking reference at 300 entities ≈ 0.019.

## Failure modes

| Relation type | MRR | Attribution |
|---|---|---|
| antisymmetric | 0.0193 | DistMult is direction-blind; too little data for TransE/RotatE to learn direction |
| one-to-many | 0.0211 | high fan-out dilutes signal; candidate entropy is high |
| composition | 0.0600 | first-order composition needs more training for RotatE to lock in |
| symmetric | 0.7042 | easy pattern, learned by all models |

## Limitations & bias

- Evaluated only on synthetic KGs; not validated on FB15k-237 / WN18RR.
- Absolute MRR is modest because the synthetic KG is very sparse
  (1000 facts over 300 entities × 8 relations).
- The fusion gain depends on base-model **complementarity**; with homogeneous
  base models the gain converges to zero.
- `max_consensus` was measured **worse** than every base model (0.1166 vs 0.1717) and is
  retained only as a documented negative result.

## Ethical / operational notes

No personal data, no licensed corpora, no external model weights. Deterministic and
offline by design, which makes results auditable and reproducible.
